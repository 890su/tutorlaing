# Карта меню Tutorlaing

Актуально для Telegram UI navigation v6. Карта описывает язык, который видит
ученик; callback указан только как техническая проверка маршрута.

## Постоянная нижняя клавиатура

| Раздел | Когда открыть | Что внутри |
|---|---|---|
| `Сегодня` | Не хочется выбирать | Один рекомендуемый следующий шаг |
| `Учиться` | Нужна языковая практика | Разговор из жизни, короткое упражнение, повторение, сохранённые занятия |
| `Помощник` | Есть своя фраза или вопрос | Проверка, перевод, перефразирование, грамматика; дополнительные упражнения |
| `Профиль` | Хочу управлять курсом | Цель, уровень, языки, напоминания, приватность и прогресс |

Нижние кнопки не отвечают на задание. Inline-кнопки под карточкой относятся
только к её текущему состоянию.

## Сегодня

Одна рекомендация по порядку: продолжить незавершённое, выполнить готовый
повтор, начать ближайшую тему, выбрать разговор. Дополнительно доступны
`Учиться`, `Прогресс и план`, `Профиль`; при открытых sessions — `Мои занятия`.

## Учиться

| Пункт | Callback | Результат |
|---|---|---|
| `Мои занятия` | `activities:list` | Сохранённые ситуации, разговоры с поворотами и тренировки с позицией |
| `Подготовиться к разговору` | `learn:conversation` | Сначала выбирается глубина подготовки, а не внутренний тип задания |
| `Быстро потренироваться · 1–2 мин` | `background:menu:practice` | Синонимы, формы, определения и смысл текущей темы; свободный ввод |
| `Повторы` | `reviews:list` | Материал, который пора вспомнить |
| `Разобрать мои слабые места` | `drill:start` | Персональная тренировка по истории ответов |

После выбора подготовки к разговору:

| Пункт | Callback | Результат |
|---|---|---|
| `Коротко отрепетировать ситуацию` | `scenarios:list` | Короткая жизненная репетиция |
| `Пройти разговор с поворотами` | `quests:list` | Вариативный разговор с меняющимися обстоятельствами |

Оба маршрута принимают только свободную реплику. Подсказка не показывает
готовый ответ. Начатые занятия не вытесняют друг друга: один выбран как
foreground, остальные отображаются с положением в `Мои занятия`.

## Помощник

Главная инструкция: отправить свою фразу в чат. Вне задания бот создаёт
привязанную к фразе карточку: проверить ошибки и естественность, перевести в
нужном направлении, перефразировать в трёх регистрах или объяснить грамматику.

Дополнительные функции помощника: `Слова и смысл · текущая тема`, персональное
закрепление, переводные карточки с четырьмя вариантами и тематическая
тренировка. Они не меняют и не удаляют основное занятие.

## Профиль

Верхний экран настроек содержит `Языки и уровень`, `О себе и цели`,
`Напоминания`, `Как пользоваться`, `Данные и приватность`. Экран прогресса
показывает рабочий уровень, закреплённые ситуации, фокус и ближайший план.

## Slash-команды

`/start`, `/activities`, `/practice`, `/tools`, `/progress`, `/settings`,
`/help`, `/grammar`, `/privacy`, `/delete_me`. Это текстовые входы в те же
разделы и служебные действия; команда не является ответом активному заданию.

## Инварианты

- один экран показывает один основной action;
- любой новый формат входит в `Учиться` или `Помощник`, а не создаёт новый
  верхний раздел;
- только foreground-занятие получает следующий свободный текст;
- переходы по меню не меняют session id и позицию;
- semantic practice всегда использует свободный ввод и не содержит ответа в
  условии;
- старые A/B/C/D карточки явно названы переводными.
