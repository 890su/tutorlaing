# Карта меню Tutorlaing

Актуально для Telegram UI после navigation v5. Карта описывает пользовательские
названия и назначения; callback приведён рядом для проверки маршрута.

## Постоянная нижняя клавиатура

| Раздел | Назначение |
|---|---|
| `Сегодня` | Один рекомендуемый следующий шаг, прогресс и настройки |
| `Мои занятия` | Все незавершённые ситуации, миссии и тренировки с позицией |
| `Практика` | Выбор учебного формата |
| `Инструменты` | Короткие упражнения, перевод и работа со своей фразой |

Кнопки не являются ответами задания. Нажатие открывает новую актуальную
workspace-карточку; inline-действия принадлежат только видимой карточке.

## Сегодня

Первой показывается ровно одна рекомендация: продолжить текущий шаг, пройти
готовый повтор, начать следующую тему либо выбрать ситуацию. Дополнительные
переходы: `Мои занятия` при наличии открытых sessions, `Практика`, `Прогресс и
план`, `Настройки`.

## Практика

| Пункт | Callback | Что открывает |
|---|---|---|
| `Мои занятия` | `activities:list` | Показывается только при наличии открытых sessions |
| `Ситуации` | `scenarios:list` | Короткие репетиции реального разговора |
| `Миссии` | `quests:list` | Вариативные разговоры со свободным вводом |
| `Слова и смысл · текущая тема` | `background:menu:practice` | Синонимы, антонимы, формы, определения и значения |
| `Повторы` | `reviews:list` | Материал, срок повторения которого наступил |
| `Закрепление` | `drill:start` | Слабые места из истории ответов |

## Инструменты

| Пункт | Callback | Что открывает |
|---|---|---|
| `Слова и смысл · текущая тема` | `background:menu:toolkit` | Свободный ввод по semantic material текущего занятия |
| `Мои ошибки · закрепить` | `drill:start` | Персональный drill по истории |
| `Переводные карточки · 4 варианта` | `toolkit:start:cards` | Старый отдельный формат с A/B/C/D и `Не помню` |
| `Перевести свою фразу → …` | `toolkit:translate:to_target` | Перевод на изучаемый язык |
| `Понять фразу на …` | `toolkit:translate:from_target` | Перевод с изучаемого языка |
| `Сценарий · выбрать тему` | `toolkit:topics` | Пять разных заданий по выбранной ситуации |

`Слова и смысл` намеренно доступен и из `Практики`, и из `Инструментов`: это
один экран и один use case, а не два разных режима. Он перечисляет только типы,
для которых есть валидный material в текущей или связанной теме. Если активной
темы нет, экран предлагает продолжить сохранённое занятие либо выбрать ситуацию.
После ответа доступны `Ещё упражнение` и возврат к исходной позиции занятия.

## Мои занятия

Каждая строка содержит kind, название, статус и текущую позицию. Выбор меняет
только foreground; остальные sessions остаются сохранёнными. Отдельной скрытой
overlay-сессии у инструментов нет.

## Настройки

Верхний экран: `Языки и уровень`, `Профиль ученика`, `Напоминания`, `Как
пользоваться`, `Конфиденциальность`. Языковой экран раздельно управляет target,
interface/instruction и translation language, а также рабочим уровнем A0–C1.

## Slash-команды

`/start`, `/activities`, `/practice`, `/tools`, `/progress`, `/settings`,
`/help`, `/grammar`, `/privacy`, `/delete_me`. Каталог регистрации Telegram и
text router используют один `PUBLIC_COMMANDS`; команды с суффиксом `@BotName`
нормализуются. `/tools` ведёт в экран, где первым пунктом видны `Слова и смысл`.

## Проверяемые инварианты

- каждый literal inline callback имеет router branch;
- reply keyboard одинакова по структуре на ru/uk/en/pl;
- slash-каталог и text router содержат один набор команд;
- semantic exercise использует свободный ввод и не содержит ответ в cue;
- переход в меню и возврат не меняют session id и текущую позицию;
- старые A/B/C/D-карточки явно названы переводными и не смешиваются с
  semantic active recall.
