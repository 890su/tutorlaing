# Dogfooding journal

Одна запись создаётся для одной реальной жизненной ситуации. Не подменяйте
наблюдение общим впечатлением «было полезно».

## Шаблон записи

- Дата:
- Сценарий:
- Когда предстоит реальная ситуация:
- Уверенность до тренировки, 1–5:
- Диагностический ответ:
- Bottleneck, выбранный продуктом:
- Был ли bottleneck действительно главным:
- Что тренировалось:
- Результат немедленной повторной попытки:
- Результат проверки через 2–7 дней:
- Что произошло в реальной жизни:
- Удалось ли выполнить задачу: да / частично / нет:
- Неожиданный вопрос или реплика собеседника:
- Уверенность после ситуации, 1–5:
- Что изменить в сценарии или алгоритме:

## Минимальный цикл founder test

1. Пройти не менее пяти разных сценариев.
2. Не использовать идеальные ответы при первой попытке.
3. Выполнить хотя бы три отложенные проверки.
4. Применить минимум два сценария в реальной жизни.
5. Зафиксировать случаи, где оценка продукта расходится с реальным успехом.
6. После этого пригласить внешних пользователей; опыт автора остаётся n=1.
