# Tutorlaing context

Telegram-first адаптивный тренер практического польского и английского для
мигрантов в Польше. Ценность продукта — суметь выполнить реальную языковую
задачу повторно и самостоятельно, а не накопить уроки.

## Что реализовано

- Python 3.11, SQLite, Telegram webhook; локальный polling оставлен fallback.
- 8 курируемых бытовых ситуаций на польском и английском; четыре вариативных
  квеста с самостоятельным вводом и сохраняемой позицией.
- AI-проверка свободных ответов через OpenAI с Gemini failover; rule-based
  диагностика остаётся независимым fallback.
- Раздельные язык интерфейса, языка перевода и изучаемого языка (`pl`/`en`);
  рабочая сложность A0–C1 и добровольный контекст ученика.
- Сохраняемые параллельные занятия: только одно foreground ждёт текст, другие
  видны в `Мои занятия` со статусом и позицией.
- Отдельные side-channels: преподаватель не меняет ход разговора; фоновая
  микро-практика не меняет foreground session.
- `LearningCardSeed` валидирует semantic active recall: синонимы, антонимы,
  определения, значения в контексте, формы и перевод. Эти карточки принимают
  только свободный ввод; польский контент требует ручной проверки до beta.
- Opt-in reminders с quiet hours, паузой, retry и одним заданием на slot.
  Непрочитанная proactive-карточка не дублируется до реакции или следующего
  дня; после отправки действует двухчасовой cooldown. Автоматическая связанная
  микро-практика пока только intensive/aggressive.
- Navigation v6: `Сегодня`, `Учиться`, `Помощник`, `Профиль`. Форматы
  (`ситуация`, `миссия`, карточки, drill) скрыты за намерением пользователя.
- Локально проходят 173 автоматических теста после P0 и первого среза P1.

## Текущая работа

P0 начат и частично реализован: новая навигация и путь
`Учиться → Подготовиться к разговору → короткая репетиция / разговор с
поворотами`. Следом нужен ручной dogfooding трёх пользовательских сценариев.
P1: управляемая частота напоминаний, дневной лимит и единые действия.
P2: персональный план дня и privacy-safe продуктовые метрики.

## Технические границы

- Модульный монолит: приложение координирует flow; `menu`, `toolkit`,
  `background_learning`, `coach`, `progress` и `reminders` имеют узкие
  Protocol-контракты. Подробно: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
- UI: reply keyboard — постоянные назначения; inline — действия видимой
  карточки; slash-команды — текстовые входы и служебные операции.
- Будущая монетизация подключается только через `EntitlementPolicy` и
  `UsageMeter`; учебный flow не знает тарифов и платёжных SDK.
- README, PLAN и ROADMAP описывают фактический статус; устойчивые решения —
  в `decisions.md`.

## Deployment и безопасность

- Docker image публикуется в GHCR. Runtime: `srv-150`,
  `~/services/tutorlaing`; текущая ветка не развёртывается автоматически.
- Последняя подтверждённая production-версия — `sha-ac98eb2`, Docker healthy;
  public health отвечал HTTP 200 2026-08-07. Более новая menu-ветка ещё не
  подтверждена по SSH из-за нестабильного WireGuard/CGNAT.
- Доступ описан в `deploy/ACCESS.md`. В проекте нет и не должно быть private
  keys, token, Telegram ID или содержимого `.env`.
