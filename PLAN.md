# План Tutorlaing

Актуально на 2026-10-06. Исторический MVP-план перенесён в
[`archive/docs/PLAN_legacy_2026-08-07.md`](archive/docs/PLAN_legacy_2026-08-07.md).

## Фактическое состояние

- Telegram-first alpha: Python, SQLite, webhook, Docker/GHCR.
- Реализованы scenario, вариативный разговор, AI-проверка свободного ввода с
  OpenAI-first/Gemini-failover и rule-based fallback.
- Пользователь может вести несколько занятий, возвращаться к позиции, открыть
  преподавателя или фоновую микро-практику без потери основного диалога.
- Семантические карточки используют свободный ввод; польский контент перед beta
  требует ручной языковой проверки.
- Локальная проверка: 240 тестов. Последняя подтверждённая production-версия:
  `sha-eb56f03`; VM использует digest `sha256:76678ecb47df…` (2026-10-06).

## P1 — напоминания под контролем ученика

- [x] Понятные названия частоты вместо внутренней агрессивности.
- [ ] Дни, активные часы и timezone.
- [x] Дневной бюджет, двухчасовой cooldown и одна неотвеченная
  proactive-карточка до реакции ученика либо следующего дня.
- [ ] Универсальные действия reminder: начать, отложить, хватит на сегодня,
  изменить режим.
- [x] Невлияющий на учебное состояние предпросмотр настройки.
- [x] Отдельный opt-in режим «карточка каждый час»: AI-пачка сохраняется в
  SQLite, кнопка `Знаю` создаёт две free-text проверки, после которых карточка
  становится выученной и исключается из выдачи.

## Расширение платформы — игры вдвоём

- [x] Изолированный Telegram Mini App без внутреннего игрового ника.
- [x] Приглашение по Telegram `@username` либо одноразовой ссылке; серверная
  авторизация Telegram и крестики-нолики с сохранением партии.
- [x] Двухпользовательский подкидной «Дурак»: скрытые руки, козырь, добор,
  атака/отбой/подкидывание и серверная проверка правил.
- [x] Двухпользовательский «Морской бой»: автоматическая расстановка флота, скрытые поля
  соперника, радар выстрелов и серверная проверка каждого хода.
- [ ] Ручной тест на мобильных клиентах Telegram после deploy: приглашение по
  `@username`, ссылка, принятие, завершение и один полный раунд «Дурака».
- [ ] Ручной тест «Морского боя» на мобильных клиентах Telegram: приглашение, принятие,
  попадание, промах, завершение и сдаться.

## P2 — личный план и измерение пользы

- [ ] Добровольный план дня: доступное время, ближайшая цель, типичная неделя.
- [ ] Ясный объём: 2 минуты, 10 минут или подготовка к событию.
- [ ] Privacy-safe события выбора маршрута, возврата и завершения.
- [ ] `EntitlementPolicy`/`UsageMeter` как отдельные адаптеры для будущей
  монетизации.

## Обязательные gates

- Польский учебный контент проходит ручную проверку до открытой beta.
- Dogfooding и внешние пользователи подтверждают понятность навигации и
  перенос навыка в реальную ситуацию.
- AI-сбой не может заблокировать учебную петлю; секреты не попадают в Git.
